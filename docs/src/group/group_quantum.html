7.1 대칭과 물리

해밀토니안 \(H = T+V\) 인 양자역학 시스템을 생각하자 그리고 해밀토니안 \(H\) 에 어떤 기하학적인 대칭이 존재한다고 하자. 운동 에너지 \(T\) 는 회전과 병진에 대해 자체로 불변이기 때문이기 때문에 해밀토니안 \(H\) 에 어떤 공간대칭성이 있다면 포텐셜 에너지 \(V\) 의 대칭성이다.

해밀토니안 \(H\) 의 대칭성이라는 것은 어떤 symmetry group 에 대해 \(H\) 가 불변임을 의미한다. 이 symmetry group 을 \(S_H\) 라고 하면 \(\forall \mathcal{R}\in S_H\) 에 대해 \(\mathcal{R}(H) = H\) 임을 의미한다. \(H\) 에 대해 \(E\) 의 고유값을 갖는 고유상태 \(\phi\) 를 생각하자. 가 \(H\) 의 고유상태이고 고유값 \(E\) 를 가질 때 \(\mathcal{R}(\phi)\) 도 그러하다는 것을 의미한다. 즉

\[ H\phi = E\phi \iff H\mathcal{R}(\phi) = E\mathcal{R}(\phi). \tag{7.1}\]

예제 7.1 식 7.1 를 보자. 양자역학에서 대칭 변환 \(\mathcal{R}\) 은 유니타리 연산자로 표현되며 이를 \(R\) 이라고 하자. 그렇다면

\[ \mathcal{R}(H)= R^\dagger HR,\qquad \mathcal{R}(\phi)=R\phi \]

이다. 해밀토니안이 \(\mathcal{R}\) 에 대해 불변이라면

\[ R^\dagger H R = H \iff HR = RH \]

임을 의미한다. 따라서

\[ H\mathcal{R}(\phi) = HR\phi = R(R^\dagger HR)\phi = R(H\phi)= RE\phi = ER\phi = E\mathcal{R}(\phi) \]

이다.


이 symmetry group \(S_H\) 의 성분을 차례로 적용함으로서 \(H\) 에 대해 같은 고유값 \(E\) 를 갖는 고유상태의 집합을 구성 할 수 있다. 즉

\[ \{\mathcal{R}(\phi) : \mathcal{R}\in S_H\} \tag{7.2}\]

가 그것이다. 만약 모든 \(\mathcal{R} \in S_H\) 에 대해 \(\mathcal{R}(\phi) = \phi\) 라면 \(\phi\) 가 \(H\) 의 전체 대칭성을 가진다고 표현하며 고유값 \(E\) 에 대한 고유벡터는 \(\phi\) 하나 뿐이다. 그렇지 않다면 \(E\) 에 대한 고유벡터의 집합은 \(\phi\) 이외의 파동함수를 포함며 각각의 고유벡터는 부분적인 \(H\) 의 대칭성 가운데 일부를 표현하고, 전체 고유벡터의 집합은 전체 대칭성을 표현한다. 예를 들어 수소원자의 \(p\) 상태는 3개의 벡터로 이루어진 집합이다. \(p\) 파동함수 각각은 수소 원자의 구면 대칭을 표현하지 못하지만 이 세 \(p\) 파동함수의 선형결합은 임의의 방향성을 표현 할 수 있다.

이제 식 7.2 로 부터 얻은 벡터의 집합을 이용하여 정규직교 기저 \(\mathcal{B}=\{\phi_i:i=1,\ldots,\,N\}\) 를 얻었다고 하자. 그렇다면 \(\mathcal{R}(\phi_i)\) 를 \(\{\phi_i\}\) 의 선형결합으로 표현 할 수 있으며, 따라서

\[ \mathcal{R}(\phi_i) = \sum_j R_{ji} \phi_j \tag{7.3}\]

라고 쓸 수 있다. 또한 \(\mathcal{T}\in S_H\) 에 대해

\[ \mathcal{T}(\phi_j) = \sum_j T_{kj} \phi_k \tag{7.4}\]

라면 \[ \mathcal{T}(\mathcal{R}(\phi_i)) = \sum_j R_{ji}\mathcal{T}(\phi_j) = \sum_{kj} T_{kj}R_{ji}\phi_k = (TR)_{ki}\phi_k \tag{7.5}\]

로 쓸 수 있다. 이제 우리는 \(\mathcal{T},\,\mathcal{R}\) 변환은 \(T,\, R\) 로 표현되는 행렬 형태가 됨을 알 수 있다.

지금까지는 이 행렬 표현이 reducible 인지 irreducible 인지 알지 하며 기약 표현 여부는 해밀토니안의 구체적 형태와 처음의 파동함수 \(\phi\) 에 의해 결정된다. 만약 이 표현이 reducible 이라면 \(\{\phi_i\}\) 에 의한 벡터공간은 \(S_H\) 의 irreducible reprensentation 을 이루는 부분공간의 직합으로 표현 할 수 있다.


예제 7.2 1차원 해밀토니안 \(H=H(x)\) 가 \(H(-x)=H(x)\) 이며 다른 대칭은 없다고 하자. \(\sigma\) 를 반전(reflection) 연산자라고 하자. 즉 \(\sigma (f)(x) = f(-x)\) 이다(반전에 \(\sigma\) 기호를 관습적으로 많이 사용한다). 이 때의 symmetry group 을 \(C_s\) 라고 표현하며 따라서 \(C_s = \{I,\, \sigma\}\) 이다. 그렇다면 이 군에 대한 연산은 다음과 같이 정리된다.

\[ I = I^2 = \sigma^2,\qquad, I\sigma = \sigma I. \]

따라서 \(C_s\) 는 아벨군이며, 연습문제 5.8 에 따라 두개의 1차원 기약표현을 갖는다.

 (\(1\)) \(A_1\) : \(U(I)=U(\sigma)=1\),

 (\(2\)) \(A_2\) : \(U(I)=1,\, U(\sigma)=-1\).

따라서 \(H\) 의 고유함수는 우함수(even) 이거나 기함수(odd) 이다. 다른 대칭성이 없으므로 이 두 even/odd 고유함수는 degenerated 되어 있다.

우함수인 \(\phi(x)\) 부터 시작했다고 하자. \(I\phi = \sigma \phi = \phi\) 이므로 이 부분공간의 기저는 \(\phi\) 뿐이다. 이 기저로 구성된 표현은 \(A_1\) 표현이며, 따라서 이 기저를 \(A_1\) 기저라고 이름붙일 수 있다. 이제 기함수인 \(\psi(x)\) 부터 시작한다면 \(I\psi = \psi,\, \sigma \psi = - \psi\) 이므로 이 부분공간의 기저는 \(\psi\) 뿐이다. \(A_1\) 기저라는 이름을 붙일 때와 마찬가지로 \(\psi\) 를 \(A_2\) 기저라고 이름 붙일 수 있다.

만약 우함수도 기함수도 아닌 \(\chi\) 로부터 시작한다고 하자. 그렇다면 \(I\chi = \chi,\, \sigma \chi (x)= \chi(-x)\) 이다. \(\chi\) 가 우함수도, 기함수도 아니므로 \(\chi(x)\) 와 \(\chi(-x)\) 는 선형 독립이며 따라서 기저는 2개의 벡터 \(\chi(x)\) 와 \(\chi(-x)\) 로 이루어진다. 이 때

\[ \chi_e (x)= \dfrac{\chi(x) + \chi(-x)}{\sqrt{2}},\qquad \chi_o (x)= \dfrac{\chi(x) - \chi(-x)}{\sqrt{2}} \]

라고 하면 \(\chi_e(-x) = \chi_e(-x)\), \(\chi_o(-x) = - \chi_o(x)\) 이며 \(\chi_e(x)\) 와 \(\chi_o\) 는 선형독립이며, 따라서 \(\chi_e\) 는 \(A_1\) 기저, \(\chi_o\) 는 \(A_2\) 기저라고 부를 수 있다.

이렇게 해밀토니안의 대칭성을 이용하면 해밀토니안의 해에 대한 중요한 성질을 알 수 있으며, 해를 찾는 데 도움이 된다.


해밀토니안이 기하학적으로 대단히 대칭적이더라도 해밀토니안의 해는 이 대칭성을 따르는 해 뿐만 아니라 덜 대칭적인 해도 가질수 있다는 것을 알게 되었다. 예제 5.8 에서 보았듯이 \(D_3\) 대칭을 가진 해밀토니안은 완전히 대칭적인 \(A_1\) 고유함수와 부호과 교대되는 \(A_2\) 고유함수들을 가질 수 있다.


예제 7.3 (\(D_3\) 대칭성을 가진 해밀토니안) 기하학적으로 \(D_3\) 대칭성을 가진 해밀토니안을 생각하자. 그리고 우리의 해는 근사적으로 정삼각형 각각의 꼭지점 \(\boldsymbol{R}_i\) 근처에 분포하는 전자 오비탈의 선형 결합으로 표현된다고 하자. 즉, \(\boldsymbol{r}_i = \boldsymbol{r}-\boldsymbol{R}_i\), \(r_i = \|\boldsymbol{r}_i\|\) 이고 \(\phi\) 가 구면 대칭 오비탈 함수일 때,

\[ \psi(\boldsymbol{r}) = a_1 \phi(r_1) + a_2 \phi(r_2) + a_3 \phi(r_3) \]

로 기술된다고 하자.

\[ \psi_0 = \dfrac{\phi(r_1) + \phi(r_2) + \phi(r_3)}{\sqrt{3}} \]

는 \(D_3\) 군의 \(A_1\) 표현에 대한 기저이다. 3개의 오비탈이 있으므로 \(\psi_0\) 와 선형 독립인 다른 두 벡터를 구성해야 한다. 다음과 같이 하자.

\[ \psi_1 = \dfrac{-\phi(r_1) + 2\phi(r_2) - \phi(r_3)}{\sqrt{6}},\qquad \psi_2 = \dfrac{\phi(r_1) - \phi(r_3)}{\sqrt{2}}. \]

이 둘중 어느것도 \(A_1\) 이나 \(A_2\) 와 같은 뚜렷한 대칭성을 보여주지 않으며, 따라서 \(D_3\) 의 \(2\times 2\) 기약표현에 대한 기저가 되어야 한다. 이를 \(E\) 라고 부른다.

\[ \mathcal{R}\psi(\boldsymbol{r}) = \langle \boldsymbol{r}|\mathcal{R}\psi\rangle = \langle \mathcal{R}^\dagger \boldsymbol{r}|\psi\rangle = \psi(R^{-1}\boldsymbol{r}) \]

임을 생각하자. 그림 4.1 로부터 \(C_3 \psi_2 = \dfrac{-\phi(r_2)+\phi(r_3)}{\sqrt{2}}\) 임을 안다. 또한

\[ C_3 \psi_1 = -\dfrac{-\psi_1 + \sqrt{3}\psi_2}{2} = \dfrac{-\phi(r_1) + \phi(r_2) }{\sqrt{2}} \]
